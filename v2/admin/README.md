# دليل لوحة تحكم مؤسسة دعم (النسخة v2)

لوحة تحكم بسيطة لإدارة **الأخبار** و**فريق العمل** دون الحاجة لأي معرفة برمجية.

## الدخول
- الرابط: `https://elewa11.github.io/daam-website/v2/admin/`
- كلمة المرور: `admin123`

## إدارة الأخبار 📰
1. من تبويب **الأخبار** اضغط **«خبر جديد»**.
2. اختر **صورة الخبر** (تُرفع تلقائياً).
3. اكتب **الوسم** (خبر/إعلان/نشاط) و**التاريخ** و**العنوان** (عربي/إنجليزي) و**المقتطف**.
4. في **محتوى الخبر** استخدم شريط الأدوات للتنسيق:
   - عريض / مائل / تسطير
   - عناوين وأحجام خطوط
   - **ألوان النص والتظليل**
   - محاذاة، نقاط، ترقيم، روابط، وإدراج صور داخل الخبر
5. اضغط **«حفظ ونشر»**. يظهر الخبر على صفحة المركز الإعلامي خلال دقيقة تقريباً.
- للتعديل أو الحذف: استخدم أزرار **تعديل/حذف** على بطاقة الخبر.

## إدارة الفريق 👥
- من تبويب **فريق العمل** عدّل الأسماء، أو اضغط على صورة العضو لتغييرها، أو أضف/احذف عضواً.
- اضغط **«حفظ الفريق ونشره»** لتطبيق التغييرات على صفحة «من نحن».

## ملاحظات
- بعد أي نشر، ينتظر الموقع من دقيقة إلى دقيقتين حتى يُحدّث (اضغط Ctrl+Shift+R للتحديث).
- كل التعديلات تُحفظ مباشرة على GitHub؛ لا تحتاج لأي إعداد إضافي.
